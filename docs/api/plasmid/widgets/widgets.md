# Widgets

Widgets are GUI elements utilized by games to display game information to a group of players, usually applied using [GlobalWidgets](global-widgets.md).  
Plasmid includes some widgets by default, but you are encouraged to extend or make your own if they do not suit your purposes.  
The included widgets are:

- [SidebarWidget](sidebar-widget.md)
- [ScrollableSidebarWidget](scrollable-sidebar-widget.md)
- [BossBarWidget](bossbar-widget.md)
