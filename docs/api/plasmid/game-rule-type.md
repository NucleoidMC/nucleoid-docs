# Game Rule Types

--8<-- [start:content]
This contains many events that you might want to allow or disallow within a [GameSpace](./game-space/game-space.md).  
Typically used in [GameActivity::allow or GameActivity::deny](game-activity.md#allowgameruletype).  
Available Rules:

- BREAK_BLOCKS
- PLACE_BLOCKS
- PORTALS
- CRAFTING
- PVP
- HUNGER
- SATURATED_REGENERATION
- FALL_DAMAGE
- USE_BLOCKS
- USE_ITEMS
- USE_ENTITIES
- INTERACTION
- - This groups the USE_BLOCKS, USE_ITEMS and USE_ENTITIES rule types into one
- BLOCK_DROPS
- THROW_ITEMS
- PICKUP_ITEMS
- DISPENSER_ACTIVATE
- UNSTABLE_TNT
- FIRE_TICK
- FLUID_FLOW
- ICE_MELT
- CORAL_DEATH
- DISMOUNT_VEHICLE
- STOP_SPECTATING_ENTITY
- PLAYER_PROJECTILE_KNOCKBACK
- TRIDENTS_LOYAL_IN_VOID
- SPREAD_CONTAINER_LOOT
- MODIFY_INVENTORY
- MODIFY_ARMOR
- SWAP_OFFHAND
